Qwen2.5 · 0.5B Instruct

Downloads once from the listed Hugging Face publisher or converter, or from peers in the QVAC model registry for QVAC-converted speech models. Every file is checked against a pinned size and SHA-256. Installed models stay on this Mac when you switch. Review each model’s license in its details below.

Voice from Android

Download a multilingual Whisper model and Silero VAD above, then load speech. Whisper Large v3 Turbo is recommended. The phone records 16 kHz mono audio; speech appears after short pauses. Review every transcript. Read diary replies on screen; speech synthesis is unavailable.

Note backgrounds

Download an image model above, assign it, then run the short generation test. Phones send only the description the person typed and a light or dark tone. Each request loads the model (about 10 s), generates (about 40 s for Stable Diffusion 2.1 on Apple Silicon) and unloads it. Cancelling unloads the model to stop. Results are kept encrypted until the phone collects them or 24 hours pass.

Note images

After downloading Qwen3-VL, the self-test sends a generated red square through the model and enables image questions only if the model reports red. Each phone request (an image question or a page scan) loads the model, answers, and unloads it. Download EasyOCR · Latin as well to have scans cross-checked. The image is kept encrypted only until the request finishes.

Models & capabilities

Checking installed artifacts…

Writing and Whisper transcription work on paired Android phones. Other speech and image models remain download-only. Downloading preserves the active writing model. Read-aloud, image generation, OCR and embeddings are not enabled; image questions need the self-test under Note images.

Choose a model above to download or switch. Writing and speech can remain loaded together; available memory determines fit. Retry starts a new download; incomplete files cannot load. External files are never removed.

Connect a phone

Keep both devices on the same Wi-Fi. Internet is unnecessary after setup. Scan this Mac’s QR in Journal Settings, compare the phone verification code below, then approve.

Trusted devices

Stopping connections keeps trust and accepted work. Revoking a device cancels its active work, deletes retained work and prevents future access. A new QR invalidates unapproved pairing requests.

Activity

Accepted phone requests are encrypted on disk for up to 24 hours. Disconnecting does not cancel them. Quit or sleep pauses execution; interrupted work requires an explicit retry with a new ID.
